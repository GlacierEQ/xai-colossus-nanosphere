# Nanofluid Conductivity, Stability, and Pump-Penalty Scenario Models

An independent portfolio project for comparing simplified nanofluid coolant scenarios across modeled thermal conductivity, colloidal stability, settling risk, viscosity, pumping penalty, aging, blend search, and manifest export.

This repository is **not affiliated with xAI**, does not use proprietary xAI data, and is not evidence of deployment inside Colossus or any physical cooling circuit. Model outputs are comparative estimates—not laboratory measurements, material certifications, formulation recommendations, maintenance instructions, or hardware-control decisions.

## What is implemented

### Conductivity and batch scenarios

[`nanosphere_model.py`](nanosphere_model.py) provides:

- validated nanofluid and batch inputs;
- Maxwell dilute-suspension conductivity scenarios;
- Hamilton-Crosser comparative shape scenarios;
- explicit model selection that fails closed on unknown values;
- exponential half-life degradation assumptions;
- deterministic lowest-concentration blend search;
- atomic, versioned circuit-manifest export;
- explicit separation between modeled and measured conductivity.

### Stability and settling scenarios

[`stability_model.py`](stability_model.py) provides:

- validated particle, fluid, volume, size, zeta, temperature, and age inputs;
- a transparent composite stability score;
- single-particle Stokes settling estimates;
- explicit scenario risk factors;
- replacement-review signaling;
- a remaining-days estimate that respects the configured age-penalty cap and returns infinity when age alone cannot cross the monitor threshold.

### Viscosity and pump-penalty scenarios

[`viscosity_model.py`](viscosity_model.py) provides:

- validated base-fluid, concentration, temperature, and shape inputs;
- a temperature-adjusted base-viscosity assumption;
- Einstein-Batchelor suspension-ratio scenarios;
- a viscosity-ratio cap by fluid class;
- pump-penalty comparison against the same modeled base fluid at the same temperature;
- deterministic concentration sweeps.

[`test_nanosphere.py`](test_nanosphere.py) verifies valid behavior, invalid inputs, deterministic selection, manifest output, threshold boundaries, age-cap handling, settling trends, viscosity trends, and same-temperature comparison semantics.

## Example

```python
from nanosphere_model import NanofluidSpec, enhancement_pct
from stability_model import StabilitySpec, evaluate as evaluate_stability
from viscosity_model import ViscositySpec, evaluate as evaluate_viscosity

conductivity = enhancement_pct(
    NanofluidSpec(
        name="portfolio-scenario",
        base_fluid="water",
        nanoparticle="Al2O3",
        volume_fraction=0.03,
        particle_size_nm=30.0,
    )
)

stability = evaluate_stability(
    StabilitySpec(
        nanoparticle="Al2O3",
        base_fluid="water",
        volume_fraction=0.03,
        particle_size_nm=30.0,
        zeta_mv=-35.0,
        age_days=30,
    )
)

viscosity = evaluate_viscosity(
    ViscositySpec(
        base_fluid="water",
        volume_fraction=0.03,
        temperature_c=30.0,
    )
)

print(conductivity, stability.status, viscosity.pump_penalty_pct)
```

## Manifest boundary

`export_circuit_manifest()` creates a local modeled JSON artifact with:

- schema version;
- timezone-aware generation time;
- explicit `MODELED_SCENARIO_NOT_TELEMETRY` state;
- recorded assumptions;
- sorted batch records;
- separate modeled and measured conductivity fields;
- atomic file replacement.

A manifest file does not prove that another repository consumed it, that a cooling system acted on it, or that the values are safe for physical use.

## Private Alpha and Omega experiments

Two private repositories remain preserved as separate research lineages:

- `xai-colossus-nanosphere-alpha` at inspected commit `1b39fae3277a034c48d62c957883fd5c3a3118ce` explores Arrhenius-rate, shear-decay, magnetic-restoration, and flocculation-suppression formulas.
- `xai-colossus-nanosphere-omega` at inspected commit `ea089c1ec15add80bc1d9ff9290fb51652773561` explores a stateful viscosity monitor and simulated recovery-loop behavior.

They are **not** counted as verified components of this public model.

Current Alpha blockers include:

- invalid Kelvin values are silently clamped to 100 K rather than rejected;
- surfactant readiness is a fixed threshold with no units or calibration;
- magnetic restoration and sweep outputs are speculative and undocumented;
- emergency behavior prints a control demand rather than producing an authority-bound proposal;
- tracked compiled artifacts were observed.

Current Omega blockers include:

- execution mutates tracked `.shadow_memory.json` state;
- an out-of-band sentinel file forces dosing state;
- a 2.0-tesla recovery pulse is represented only by an in-memory variable and `sleep()`;
- “viscometer calibration,” dosing, and electromagnetic-control language is unsupported by sensors or hardware;
- runtime state, tests, and source are not cleanly isolated.

No repository is deleted, collapsed, or presented as physical-control capability. Each private experiment requires its own validation, state-isolation, authority, safety, and claim review before promotion.

## Safety and interpretation

- Every output depends on caller-supplied scenario values.
- Unknown materials, fluids, shapes, models, invalid concentrations, non-finite values, and invalid ages fail closed.
- A modeled enhancement does not establish improved heat transfer in a complete system.
- A pump-penalty estimate does not replace pump curves, Reynolds-number analysis, pressure-drop calculations, or measured rheology.
- A stability score is a transparent heuristic, not a laboratory colloidal-stability determination.
- Real formulations require materials compatibility, toxicology, environmental, filtration, corrosion, erosion, electrical, thermal, pressure, maintenance, and professional engineering review.

## Promotion requirements

Before this family supports a broader cooling-material claim, it still needs:

1. primary citations and versioned provenance for every constant and threshold;
2. uncertainty ranges and sensitivity analysis;
3. comparison against laboratory or published reference datasets;
4. additional models for concentration interactions, non-Newtonian behavior, pressure drop, corrosion, erosion, and filtration;
5. signed measured-data ingestion with units, timestamps, and calibration metadata;
6. deterministic replay fixtures and property tests;
7. independent chemical, materials, thermal, and safety review;
8. separate hardening of Alpha and Omega before any controller-family claim.
